# Hotel para Pets - App Mobile

## Descrição
Aplicação mobile para controle de animais hospedados em um hotel para pets.  
O usuário pode incluir, visualizar, editar e excluir registros de animais.

### Funcionalidades
- Cadastro de animais e tutores
- Visualização de registros
- Edição e exclusão de registros
- Cálculo automático de diárias até o momento
- Previsão de data de saída e diárias totais

## Tecnologias
- Front-end: Flutter
- Back-end: Node.js
- Banco de dados: PostgresSQL

## Configuração
Após a instalação do Flutter e do Nodejs, configure as variáveis de ambiente para que o arquivo ./backend/src/config/config.js consuma.
